# Roadmap

**Disclaimer:** items are listed in no particular order. Some have higher priority than others. Several are actively in development, while others remain under consideration and may change.

If you have thoughts about these items — or want to suggest something else — please get in touch. User feedback is one of the most important ways we prioritize work.

---

## Organizing

- **Move between folders** — move a form or view straight from one folder to another, without removing it first.
- **Nested folders** — create folders inside folders for larger form and view libraries.
- **Labels** — tag forms and views with labels, so one item can be grouped several ways at once.
- **Bulk actions** — move, remove or trash several forms or views at once from inside a folder.
- **Folder colors** — give folders a color to make them easier to tell apart at a glance.
- **Default folder** — choose a folder that new forms and views are added to automatically.

## Finding Things

- **Search** — find folders, and the forms and views inside them, from the folder screens.
- **Where it's used** — see which posts and pages embed each form or view.
- **Folder filter on the Forms list** — narrow the main Gravity Forms list to a single folder.

## Access

- **Widget visibility by role** — choose which user roles see the folder dashboard widgets.
- **Folder permissions** — limit which roles can see or manage particular folders.

## Moving Between Sites

- **Export and import** — copy your folder structure to another site along with your forms and views.

---

This roadmap will evolve as we release new capabilities and gather feedback. Stay tuned for updates.
